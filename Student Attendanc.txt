Objective: Build a Student Attendance System where teachers can
manage attendance online, and students can track their records with
calculated percentages.

Core Features:
✅ Teacher Access – Mark daily attendance and view class lists.
✅ Student Access – Check personal attendance by subject/date.
✅ Automated Percentage Calculation – Real-time attendance stats.
✅ Role-Based Authentication – Different views & permissions for teachers vs.
students.

User Authentication & Profile Setup

Login & Role Identification
Secure login with a predefined role:

Teacher: Can mark and view attendance.
Student: Can only view their own records.
Role-Based Access Control (RBAC)
Redirect users to their dashboards based on role after login.
Teachers cannot edit student accounts, and students cannot mark
attendance.
Optional Admin Role (Extension)
Create/manage users, assign teachers to classes/subjects.

Teacher Dashboard – Attendance Management

Class & Subject Selection
Teacher selects:
Subject/Class (e.g., 10th-A, Science)
Date of attendance
Marking Attendance
Display list of enrolled students with checkboxes (Present/Absent).
Default to "present" for quick marking (optional).
Submit button saves records to the database.
View Past Records
Filter past attendance by:
Subject
Date range
Percentage threshold (e.g., < 75%)


Student Dashboard – Attendance Records

Personal Record Display
Show student’s daily attendance log by subject/date.
Use a calendar view or tabular layout for clarity.

Attendance Percentage Calculation
Automatically compute attendance percentage
Update in real-time as attendance is marked.

Alerts (Optional)
Notify students if attendance drops below threshold (e.g.,
75%).


UI, Testing & Final Wrap-up

UI Suggestions
Dashboard layout:
Teacher: Class filters, quick marking grid.
Student: Charts/graphs for attendance breakdown.
Color-coded percentage indicators:
✅ Green (80%+)
⚠️ Yellow (60–80%)
🔴 Red (<60%)
Testing

✅ Role-based login routes.
✅ Accurate attendance save & update.
✅ Percentage calculation correctness.
✅ Filters and responsive layout.

Deployment
Host app with secure login endpoints.
Ensure backups for attendance data.
Optional: Export attendance reports to CSV/PDF.
